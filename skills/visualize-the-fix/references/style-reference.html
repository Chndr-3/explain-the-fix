Terms carry a dotted underline in body copy and inside SVG labels alike. The retry path uses exponential backoff, keyed off a idempotency key so replays are safe. Failures past the ceiling fall through to the dead-letter queue.

Exponential backoff
A retry schedule where each successive wait doubles, capped at a ceiling — it keeps a struggling service from being hammered by its own clients.
Idempotency key
A caller-supplied identifier that lets the server recognise a repeat of a request it already processed, and return the original result instead of doing the work twice.
Dead-letter queue
A holding queue for messages that failed every retry, kept out of the main path so they can be inspected without blocking healthy traffic.
